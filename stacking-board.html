📖 스포츠스태킹 스코어보드 사용법

준비하기

이런 곳이에요

실제 스포츠스태킹 경기 중에 점수만 터치로 올리는 전광판이에요. TV·태블릿·스마트폰에 띄워 세워 두고 써요. 기록 측정이나 AI 대결은 없어요. AI와 연습하려면 5세트 모의 경기장을 쓰세요.

시작 전 설정

  • 팀 이름: 화면 위의 "우리 팀"·"상대 팀" 글자를 눌러 바로 고쳐요. (최대 10글자)
  • ⚙️ 설정: 좌우 바꾸기, 전체 화면, 화면 켜두기, 모든 점수 처음부터.
  • TV에 띄울 때는 ⛶ 전체 화면을 켜면 숫자가 더 크게 보여요.

세트 구성 (기준)

세트종목기준
1세트3-6-3 릴레이5판 3선승
2세트개인 사이클5판 3선승 (게임 3판 2선승)
3세트더블 사이클5판 3선승 (게임 3판 2선승)
4세트시간 릴레이1판 (승패만 입력)
5세트사이클 릴레이3판 2선승

점수 올리기

세 가지 점수

  • 세트 점수: 세트를 이긴 횟수. 3이 되면 🏆가 떠요.
  • 라운드 점수: 지금 세트에서 이긴 판 수. 가장 크게 보여요.
  • 게임 점수: 개인·더블 사이클에서 한 라운드 안의 1:1 승부. 2세트·3세트에서만 보여요.

조작

  1. 이긴 팀의 점수 칸을 한 번 누르면 +1이에요.
  2. 잘못 눌렀으면 칸 구석의 − 버튼이나 가운데 ↩️ 되돌리기를 눌러요.
  3. 게임이 끝나 다음 주자로 넘어가면 게임 초기화를 눌러 게임 점수를 0 : 0으로 만들어요.
  4. 세트가 끝나면 이긴 팀의 세트 점수를 누르고, 위쪽 다음 세트 버튼을 눌러 넘어가요.

점수가 기준(예: 3선승)에 닿아도 자동으로 넘어가지 않아요. 칸이 금색으로 빛나며 "선승 도달"만 표시돼요. 그래서 기준보다 더 많은 판을 연습할 수 있어요.

팁 · 문제 해결

  • 점수는 이 기기 브라우저에 자동 저장돼요. 새로고침하거나 실수로 창을 닫아도 이어서 할 수 있어요. 학생 이름은 저장하지 않아요.
  • 위쪽 세트 버튼에 각 세트의 라운드 점수(예: 3 : 1)가 남아요. 지난 세트를 눌러 다시 볼 수도 있어요.
  • 같은 세트를 처음부터 다시 하려면 라운드 초기화(라운드·게임 점수가 0 : 0)를 눌러요.
  • 새 경기를 시작할 때는 ⚙️ → 모든 점수 처음부터를 두 번 눌러요. 팀 이름은 남아요.
  • 팀이 화면 반대편에 앉았다면 ⚙️ → 좌우 바꾸기.
  • 화면이 자꾸 꺼지면 ⚙️ → 화면 켜두기가 켜져 있는지 확인하세요. 일부 기기에서는 기기 설정의 화면 꺼짐 시간도 늘려야 해요.
  • 스마트폰은 세로로 세우면 위아래, 눕히면 좌우 대결 화면이 돼요.
  • 키보드가 있으면 Z 키로도 되돌릴 수 있어요.
