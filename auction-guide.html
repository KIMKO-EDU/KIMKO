1명화 경매란?

라운드마다 명화 한 점이 경매에 나오고, 각 조는 얼마를 낼지 다른 조 몰래 정합니다. 가장 높게 부른 조가 낙찰받아 점수를 얻지만, 돈은 낙찰받은 조만 냅니다. 같은 금액을 부르면 무효가 되고, 가장 낮게 부른 조는 점수를 잃어요. 12라운드가 끝나면 돈을 가장 많이 쓴 조는 파산으로 꼴찌가 됩니다. 이기려면 점수도 따야 하고, 돈도 아껴야 하는 눈치 게임이에요.

🧑‍🏫 진행자 화면선생님 노트북. 방 만들기, 제출 현황, 마감·판정, 총액 공개, 최종 발표. 입찰 금액이 보이니 학생에게 보이지 않게!
📺 점수판프로젝터. 입장 QR, 조별 점수·순위, 라운드별 낙찰 조, 3·6·9라운드 총액. 금액은 나오지 않아요.
🕵️ 학생 화면조별 기기. 금액 입력, 라운드 결과, 우리 조 점수와 쓴 돈. 다른 조 금액은 보이지 않아요.

2경매 규칙 (판정 방법)

[입찰 마감 · 결과 공개]를 누르면 아래 규칙대로 자동으로 판정됩니다. 기존 명화 경매 화면과 판정 방법이 똑같아요.

💰 최고가 낙찰
가장 높은 금액을 혼자 부른 조가 낙찰받아 그 라운드 점수(1~4점)를 얻어요. 낸 돈은 그 조의 지출에 쌓여요.
🤝 동점 무효
같은 금액을 부른 조가 둘 이상이면 그 금액은 모두 무효. 다음으로 높은 금액 중 혼자 부른 금액이 낙찰돼요. 모두 겹치면 유찰.
⚠️ 최저가 감점
가장 낮은 금액을 부른 조는 -1점. 최저 금액이 같은 조가 여럿이면 모두 -1점이에요.
💸 파산 패배
12라운드가 끝난 뒤 누적 지출이 가장 많은 조는 점수와 상관없이 최하위예요. 지출이 같으면 모두 파산.

예시로 보기

이번 라운드 점수 2점, 4개 조가 이렇게 입찰했다면:

조입찰결과
1조5만원2조와 같은 금액 → 무효
2조5만원1조와 같은 금액 → 무효
3조3만원무효를 빼면 가장 높은 단독 금액 → 낙찰! +2점, 지출 3만원
4조2만원가장 낮은 금액 → -1점

점수판에는 "3조 낙찰 +2", "4조 -1점"만 나오고, 3만원이라는 금액은 나오지 않아요.

순위 정하기

  • 점수가 높은 조가 위입니다. 최종 발표 전에는 점수만으로 순위를 보여 줘요.
  • 최종 발표를 누르면 파산 조가 정해지고, 파산 조는 점수와 상관없이 맨 아래로 내려가요.
  • 3·6·9라운드가 끝나면 지금까지 낙찰된 금액의 총합을 공개할 수 있어요. 어느 조가 얼마나 썼는지 짐작하게 만드는 장치예요.

처음 한 번만: 교사 인증

  1. 진행자 화면을 처음 열면 교사 인증 창이 나옵니다.
  2. 교사 코드를 입력하세요. 미스터리 타임과 같은 코드이고, 그 브라우저에서 미스터리 타임을 이미 인증했다면 묻지 않아요.
  3. 다른 노트북이나 다른 브라우저에서는 한 번 더 입력해야 합니다.
🔒 교사 코드는 학생 앞에서 입력하지 마세요. 프로젝터에 연결하기 전에 미리 인증해 두세요.

프로젝터 연결: "확장" 모드 추천

진행자 화면에는 모든 조의 입찰 금액이 보여요. 노트북 화면과 프로젝터 화면을 따로 써야 학생들이 금액을 보지 못합니다.

윈도우Win + P → 확장 선택
맥시스템 설정 → 디스플레이 → 미러링 끄기

진행자 화면의 [📺 점수판 열기]로 새 창을 연 뒤 프로젝터 화면 쪽으로 끌어다 놓고 F11로 전체 화면을 만드세요. 확장이 어렵다면 교실 PC에서 점수판 주소를 따로 열어도 됩니다.

시간선생님학생

5진행자 화면 사용법

① 방 만들기

  • 조 수: 3~8조 중에서 고르세요. 처음에는 4~5조를 추천해요.
  • 진행자 PIN: 숫자 4~6자리. 노트북이 꺼져 다른 기기로 이어서 진행할 때 필요하니 꼭 메모해 두세요.

② 대기실

  • 방 코드와 QR이 나옵니다. 조가 들어오면 ● 접속 중으로 바뀌어요.
  • 모든 조가 들어오지 않아도 시작할 수 있어요. 기기가 없는 조는 진행 중에 선생님이 대신 입력하면 됩니다.
  • [▶ 경매 시작]을 누르면 1라운드 입찰이 열립니다.

③ 라운드 진행 (입찰 받는 중)

  1. 이번 라운드 초코점수를 [−] [+]로 정하세요 (1~4점, 기본 1점). 학생 화면과 점수판에 바로 보여요. 귀한 명화일수록 점수를 높이면 재미있어요.
  2. 조들이 입찰하면 표에 ✅ 제출과 금액이 나타납니다. 학생은 마감 전까지 금액을 바꿀 수 있어요.
  3. 기기가 없거나 꺼진 조는 대신 입력 칸에 금액을 넣고 [저장]을 누르세요.
  4. 모든 조가 제출해야 [입찰 마감 · 결과 공개] 버튼이 눌립니다. 누르는 순간 입찰이 닫히고 판정 결과가 모든 화면에 나옵니다.

④ 결과 공개 후

  • 판정 요약에 낙찰 조, 지출 금액, 감점 조, 동점 무효 조가 나와요. 금액은 진행자 화면에만 보여요.
  • [↩ 이 라운드 다시 입찰받기]: 입력 실수가 있었을 때 두 번 누르면 판정을 취소하고 입찰을 다시 받아요. 조들은 금액을 고칠 수 있어요.
  • [N라운드 시작 ▶]: 다음 라운드로 넘어갑니다.
  • 3·6·9라운드가 끝나면 파란 안내 칸에 지금까지의 낙찰 총액이 나와요. [아이들에게 총합 공개]를 누르면 학생 화면과 점수판에 함께 공개됩니다. 누르지 않으면 공개되지 않아요.

⑤ 최종 발표

  • 12라운드 결과가 나오면 [🏁 최종 발표 (파산 조 공개)] 버튼이 생겨요. 두 번 눌러야 실행됩니다.
  • 파산 조가 정해지고, 모든 조의 점수·순위·쓴 돈이 학생 화면과 점수판에 공개돼요. 점수판에는 우승 조가 크게 나옵니다.
  • 오른쪽 조별 누적 현황과 아래 라운드 기록 표로 라운드별 결과를 다시 짚어 줄 수 있어요.
⚠️ 경매 중에 상단의 [🏠 홈]을 누르면 한 번 더 확인해요. 실수로 닫았다면 진행자 화면을 다시 열고 "최근 만든 방"을 누르면 그대로 이어집니다.

7기존 방식과 언제 나눠 쓰나

홈에서 명화 경매를 누르면 세 가지 중에 고를 수 있어요.

🧑‍🏫 실시간 진행 (이 가이드)조마다 기기가 있을 때. 입찰 금액을 몰래 적는 종이가 필요 없고, 판정과 점수 계산이 모든 화면에 바로 반영돼요.
📝 기존 방식 (선생님이 입력)기기가 없거나 인터넷이 불안할 때. 조마다 종이에 금액을 적어 내면 선생님이 화면에 옮겨 적고 판정해요. 4조 고정이에요.

두 방식의 판정 규칙은 똑같아요. 기록은 서로 이어지지 않으니 한 수업에서는 한 가지만 쓰세요.

8이럴 땐 이렇게 (문제 해결)

노트북이 꺼졌어요 / 다른 기기로 진행하고 싶어요
다른 기기에서 진행자 화면을 열고 "진행 중인 방 이어서 하기"에 방 코드를 넣은 뒤, 방을 만들 때 정한 진행자 PIN을 입력하세요. 점수와 입찰 기록이 그대로 이어집니다.
조 기기가 꺼졌어요 / 기기를 바꾸고 싶어요
대기실의 조 자리에서 [자리 비우기]를 두 번 누르세요. 새 기기로 입장해 같은 조 번호를 고르면 이어받습니다. 새로고침 정도는 비우지 않아도 그대로 이어져요. 급하면 그 라운드만 선생님이 대신 입력해도 됩니다.
학생이 다른 조 번호를 잘못 골랐어요
대기실에서 그 조 자리를 [자리 비우기] 하고, 학생 기기에서 페이지를 새로고침한 뒤 맞는 번호를 고르게 하세요.
마감 버튼이 안 눌려요
아직 입찰하지 않은 조가 있어요. 표에서 ⏳ 기다리는 중인 조를 확인하고, 기기가 없는 조라면 대신 입력으로 금액을 넣어 주세요.
금액을 잘못 입력했다는데 이미 마감했어요
[↩ 이 라운드 다시 입찰받기]를 두 번 누르면 판정이 취소되고 입찰이 다시 열려요. 고친 뒤 다시 마감하세요. 이미 공개한 3·6·9라운드 총액도 함께 취소됩니다.
학생 화면에서 "지금은 입찰할 수 없어요"가 떠요
선생님이 이미 마감했거나 다음 라운드가 아직 시작되지 않았을 때 나와요. 다음 라운드가 시작되면 다시 입력할 수 있어요.
"권한이 없습니다"라는 오류가 떠요
Firebase 보안 규칙에 명화 경매 부분이 게시되지 않았을 가능성이 커요. 홈페이지 관리자에게 보안 규칙(firestore.rules)을 최신 버전으로 게시했는지 확인해 달라고 하세요.
점수판 화면이 멈춘 것 같아요
점수판 창을 새로고침(F5)하세요. 방 코드가 주소에 들어 있어서 바로 다시 연결됩니다.
학교 와이파이에서 접속이 안 돼요
일부 학교망은 외부 서비스(구글 Firebase)를 막기도 해요. 휴대폰 데이터로는 되는지 확인해 보시고, 안 되면 학교 정보 담당 선생님께 firestore.googleapis.com, identitytoolkit.googleapis.com, securetoken.googleapis.com, www.gstatic.com 접속 허용을 요청하세요. 급할 때는 기존 방식으로 진행하세요.

9수업 운영 팁

🗣️ 조끼리 작게 의논입찰 전에 "얼마 낼까?"를 조 안에서만 속삭이게 하세요. 다른 조에 들리면 동점 무효 작전에 당해요.
